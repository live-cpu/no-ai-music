# 🎵 AI 음악 필터링 & 유튜브 플레이리스트 생성기 v2.6

유튜브 검색 목록에서 AI 생성 음악과 1분 미만의 쇼츠(Shorts) 영상을 걸러내고 순수 인간 제작 음악 중심의 플레이리스트를 빌드해 주는 앱입니다.  
*(역설적이지만) 개발 과정에서 Gemini, GPT, Claude의 도움을 받았습니다.*

> 🔒 **보안 안내:** 사용자의 API 키는 프로그램 외부 파일이 아닌 **'OS 자격 증명(keyring)'**에 안전하게 격리 보관됩니다.

### 📢 [필독] 첫 실행 시 "PC 보호" 경고창 해결 방법

본 프로그램은 1인 개발 오픈소스 앱으로 대기업용 유료 디지털 서명이 등록되어 있지 않습니다. 바이러스가 아니니 최초 실행 시 윈도우 보호 경고창이 뜨면 아래와 같이 진행해 주세요.

1. 경고창 본문 안의 파란색 **[추가 정보]** 글씨를 클릭합니다.
2. 우측 하단에 새로 나타나는 **[실행]** 버튼을 누릅니다.
*(최초 1회만 허용해 두면 다음부터는 경고 없이 바로 정상 작동합니다.)*

### 🧠 AI 음악 차단 및 필터링 규칙 (유지 / 보류 / 제외)

프로그램이 영상 소스의 메타데이터와 제목/설명을 자동 분석하여 3단계로 분류합니다.

#### 📌 무조건 차단 (🚨 제외)
* 유튜브 스튜디오 공식 시스템에 **'변경/합성 콘텐츠(AI 제작)'** 라벨이 적용된 영상
* 설명란에 **'새롭게 생성되었습니다'** 문구와 **'AI/인공지능'** 단어가 동시 포함된 영상
* 영상 정보에 **'인공지능 음악'**, **'AI 생성'**, **'AI로 제작/창작'**, **'ai-generated'**가 명시된 영상

#### 📌 의심 흔적 감지 (⚠️ 점수 합산)
* 주요 생성형 AI 플랫폼 이름 포함 (+30점)
* AI music, AI bgm, AI cover, AI song 문구 포함 (+15점)

#### 📌 오탐 방지 및 인간 제작 예외 인정 (💚 점수 차감)
* `"not AI"`, `"AI 아님"`, `"AI를 사용하지 않은"` 등 부정 문구 감지 시 감점 (차단 방지)
* 공식 아티스트 채널, VEVO 유통망, 채널명 뒤 `'- Topic'` 포함 시 (-25점)
* 본문에 OST, Soundtrack, Theme song 등 공식 라이선스 저작물 문구 포함 시 (-35점)
* 생성형 AI 대중화 이전인 **'5년 이상 전 업로드'** 영상 (-20점)

> 💡 **판정 결과 범위**
> * **[0 ~ 24점]** : 유지 (플레이리스트 포함)
> * **[25 ~ 49점]** : 보류
> * **[50점 이상]** : 제외

### 🔑 YouTube API 키 발급 방법 (3분 소요)

프로그램 구동을 위한 무료 API 키 발급 절차입니다. (무료 한도 내 평생 이용 가능)

1. [구글 클라우드 콘솔](https://console.cloud.google.com/) 접속 및 로그인
2. 좌측 상단 **[프로젝트 선택]** -> **[새 프로젝트]** 클릭 후 생성
3. 상단 검색창에 **"YouTube Data API v3"** 검색 후 **[사용 (Enable)]** 클릭
4. 왼쪽 메뉴 **[사용자 인증 정보]** 이동 -> 상단 **[+ 사용자 인증 정보 만들기]** -> **[API 키]** 클릭
5. 발급된 키(`AIzaSy...`)를 복사하여 프로그램 입력창에 넣고 **[키 보안 저장]** 클릭!
